# api-client

Generated TypeScript client for the `ledgerline-api` HTTP surface (spec §2.3).
`scope:shared`, `type:api-client`.

**Never hand-edited.** Everything under `src/` is regenerated from the OpenAPI
schema the API emits at build time; edits here are overwritten. Change the
Fastify route schemas and regenerate.

Currently a stub — the API does not exist yet. The lib is created ahead of it so
§2.2's `type:api-client` boundary (`onlyDependOnLibsWithTags: []`) is in place
before any code is written against it.
